AutoCrop для Telegram — на основе AutoCrop Windows v1.4

Это отдельная версия Telegram-бота с исходным алгоритмом кадрирования.
Оконный интерфейс и сборщик EXE не нужны. Исходный архив не изменён.

БЫСТРЫЙ ЗАПУСК НА WINDOWS

1. Полностью распакуйте архив, например в C:\AutoCrop_Telegram.
2. Установите Python 3.12 x64 с pip. Отметьте «Add Python to PATH».
   Рекомендуется Python 3.12; код рассчитан на Python 3.10+.
3. В Telegram откройте официального @BotFather: https://t.me/BotFather
   Отправьте /newbot, задайте имя и username. Сохраните выданный токен.
   Токен — пароль к боту. Не присылайте его в чат и не публикуйте.
4. Скопируйте config.example.json в config.json (рядом с bot.py).
   Вместо PASTE_TOKEN_HERE вставьте токен.
   В ALLOWED_USER_IDS укажите свой числовой Telegram ID, например:
   "ALLOWED_USER_IDS": "123456789"
   Для нескольких пользователей: "123456789,987654321".
   Это числовой ID, а не @username и не номер телефона.
5. Если свой ID неизвестен: временно укажите "1", запустите бота
   и отправьте ему /id. Бот ответит вашим ID даже без доступа к обработке.
   Остановите бота (Ctrl+C), замените "1" на полученный ID и запустите снова.
6. Дважды щёлкните start_windows.bat. При первом запуске установятся
   библиотеки; нужен интернет. Окно консоли должно оставаться открытым.
   Если config.json отсутствует, токен и ID будут запрошены в консоли;
   ввод токена скрыт, эти значения на диск не записываются.
7. Откройте своего бота в Telegram, нажмите Start и отправьте изображение.
   Для сохранения качества отправляйте изображение как ФАЙЛ.
   Результат возвращается документом: скачайте его из ответа бота.

КОМАНДЫ

/start, /help          Справка
/padding 10           Отступы 10% со всех сторон
/padding 5 10 5 15    Слева 5%, сверху 10%, справа 5%, снизу 15%
/settings             Показать отступы
/reset                Вернуть 10% со всех сторон
/id                   Показать свой числовой Telegram ID

Отступы допустимы от 0 до 100%, считаются от размера найденного объекта.
У края снимка отступ ограничивается доступным фоном.
У каждого разрешённого пользователя свои настройки до перезапуска бота.
Альбом обрабатывается по одному изображению, результаты приходят отдельно.
Бот работает только в личных чатах, только для ID из ALLOWED_USER_IDS.

ФОРМАТЫ И КАЧЕСТВО

Вход: JPG/JPEG, PNG, BMP, TIFF, WebP; до 20 000 000 байт и 24 млн пикселей.
Поддерживается один кадр: анимация и многостраничные TIFF отклоняются.
Алгоритм лучше всего подходит для одной книги/объекта на однородном фоне.
Перед массовым использованием проверьте несколько ваших снимков.
Это кадрирование по прямоугольнику, без удаления фона или выравнивания перспективы.

PNG/TIFF сохраняют прозрачность и 16-битные данные при поддержке кодека.
Обрезанный WebP сохраняется как PNG; JPG кодируется с качеством 95.
Поворот и отражение EXIF учитываются до кадрирования.
При отсутствии обрезки и преобразования ориентации возвращаются исходные байты.
При повторном кодировании метаданные EXIF/ICC не переносятся.
Обычные фото Telegram может сжимать ещё до получения ботом.
Результат ограничен 49 MB; при превышении бот попросит меньший исходник.

РАБОТА И ЗАПУСК НА СЕРВЕРЕ

Бот работает, пока запущен bot.py и компьютер подключён к интернету.
Закрытая консоль, выключенный компьютер или спящий режим остановят обработку.
Для работы 24/7 перенесите папку на постоянно включённый ПК или VPS.
Отдельный домен, публичный IP и входящие порты не нужны: используется long polling.
Нужен исходящий HTTPS к api.telegram.org и доступ к PyPI для установки.

Linux/macOS:
  python3 -m venv .venv
  .venv/bin/python -m pip install -r requirements.txt
  .venv/bin/python bot.py

Можно задать TELEGRAM_BOT_TOKEN и ALLOWED_USER_IDS в переменных среды
вместо config.json. Переменные среды имеют приоритет.
Для постоянного сервера задайте автозапуск через systemd/диспетчер служб.
Сам этот комплект не настраивает сервер и не регистрирует службу.
Файлы обрабатываются в оперативной памяти без сохранения локальных копий.
Загрузка и ответы проходят через Telegram и остаются в чате по его правилам.
Обработка последовательная, рассчитана на личное использование/небольшую команду.
Настройки и offset хранятся в памяти: после аварии возможен повтор последнего ответа.
После ошибки отправки пришлите изображение повторно.

ЕСЛИ НЕ РАБОТАЕТ

Версия комплекта 1.1: подробная диагностика запуска без вывода токена.
Теперь отдельно сообщаются ошибки JSON (строка/столбец), неправильные
поля конфигурации, config.json.txt, отказ API, DNS, TLS и тайм-ауты.
Для обновления с 1.0 достаточно заменить bot.py; свой config.json сохраните.
Если ошибка осталась, передайте текст нового сообщения, без токена.

401/404: проверьте токен. При утечке отзовите его через @BotFather.
409: остановите другие копии этого бота.
Webhook: используйте отдельного бота или самостоятельно отключите прежний webhook.
Комплект проверяет webhook и не отключает его автоматически.
Нет доступа: проверьте ALLOWED_USER_IDS и перезапустите бота.
Нет подключения: проверьте доступ к api.telegram.org на вашем ПК/сервере.
Ошибка установки: проверьте версию Python, интернет и вывод pip в консоли.

ПРОВЕРКИ И СОСТАВ

crop_core.py — алгоритм из исходного auto_crop.py, без Tkinter.
bot.py — Telegram Bot API, контроль доступа и обработка в памяти.
start_windows.bat — создание среды, установка зависимостей и запуск.
config.example.json — образец, не содержит настоящего токена.
tests/test_bot.py — автоматические проверки с подменой Telegram API.

Запуск проверок:
  python -m unittest discover -s tests -v

Проверено в Linux с Python 3.12, NumPy 2.5.4, OpenCV 5.0.0, Pillow 13.0.0.
Проверки не подключаются к Telegram. Живой обмен с ботом и запуск .bat на Windows
в этой среде не проверены — для этого нужен ваш токен и ваш компьютер.

Документация Telegram: https://core.telegram.org/bots/api

НОВОЕ В ПАТЧЕ v1.2 CV

Новые модули обнаруживают четырёхугольник книги, выполняют осторожное
выравнивание наклона и перспективы, ослабляют мягкие тени. При низкой
уверенности применяется старый crop_core.py или возвращается исходник.
Функции включаются флагами IMAGE_PROCESSING в config.json. Чтобы полностью
вернуть поведение v1.1, укажите "enabled": false; для режима только
поворота — "rotation_only": true. Команды бота не менялись.
Смотрите README_CV.md: параметры, диагностика, тесты, ограничения и риски.


ДОПОЛНЕНИЕ ДЛЯ ВЕРСИИ v1.3.0 (актуальные параметры)

Теперь тени и лёгкий контраст обрабатываются и при сообщении
«четырёхугольник не подтверждён». Перспектива по умолчанию выключена.
Небольшой поворот раскрытой книги возможен по двум согласованным границам.

При перезапуске по умолчанию сбрасывается очередь накопленных Telegram-
сообщений: "flush_updates_on_start": true (верхний уровень config.json).
Чтобы обработать накопившиеся сообщения после простоя, установите false.

Для диагностики доступа несколько ID указывают через запятую. Переменная
окружения ALLOWED_USER_IDS имеет приоритет над config.json.
