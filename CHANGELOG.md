# CHANGELOG — AutoCrop Telegram

История версий подтверждена исходным архивом v1.1 и коммитами GitHub. Новые версии создаются отдельными коммитами/PR. Не включать в репозиторий реальные фото пользователей, конфигурацию с токеном или debug-снимки.

## v1.3.0 (2026-11-21) — crop, свет и читаемость книг
- По вашим фотографиям закрытой и раскрытой книги исключена необходимость исправлять перспективу по умолчанию: `perspective_enabled=false`, `rotation_only=true`. Режим perspective остаётся доступен только явным opt-in.
- Исправлен основной дефект v1.2: при `confidence=0` / `четырёхугольник не подтверждён` после обычной обрезки **выполняется коррекция мягких теней и контраста**.
- Добавлен `contrast.py`: ограниченное усиление локальных деталей текста в канале яркости, маска нейтральной бумаги, без глобальной смены цвета обложки.
- Добавлен консервативный `line_deskew` для раскрытых книг с двумя согласованными длинными линиями; 6° максимум, без перспективного искажения.
- После перезапуска очередь старых Telegram updates по умолчанию очищается через `getUpdates(offset=-1)`. Опция `flush_updates_on_start=false` сохраняет очередь. **При очистке старые сообщения не обрабатываются.**
- Существующие команды, список разрешённых пользователей, EXIF/alpha/16-bit и оригинальный алгоритм crop не заменены.
- Тесты и документация дополнены; локально проверено **51 тест** на Python 3.13/OpenCV 4.13. Три предоставленные фотографии использовались локально без публикации.
- Отдельная проверка CI, Windows и реального Telegram всё ещё требуется перед утверждением качества.

## Правило следующих ревизий
Каждый PR документирует: **исходная проблема → причина → изменение → тест → риск**. Предпочтителен отдельный релизный тег и неизменяемый коммит, а не переписывание истории.
