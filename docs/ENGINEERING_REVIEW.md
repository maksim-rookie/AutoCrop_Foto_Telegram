# Инженерная рецензия AutoCrop Telegram — v1.1–v1.3

Источник проверки: предоставленный архив v1.1, история коммитов GitHub, три фотографии пользователя (старые раскрытые книги и цветная закрытая). **Фотографии не сохраняются в репозитории.**

| Проблема / ревизия | Причина | Принятое улучшение | Проверка и риск |
|---|---|---|---|
| v1.1: только crop | Нет CV-геометрии и коррекции света | v1.2: OpenCV, тени, deskew | Неуверенная геометрия у раскрытых книг |
| v1.2.0: тени пропускаются при fallback | Shadow этап был вложен в ветку подтверждённой геометрии | v1.3: освещение/контраст выполняются и после legacy crop | Реальные сложные тени могут остаться |
| v1.2.0: перспективный warp включён по умолчанию | Внешний контур книги принят за плоский документ | v1.3: перспектива выключена, opt-in сохранён | Для круто снятых обложек остаётся перспектива |
| v1.2.1: OpenCV Hough возвращает разные формы | `lines[:,0]` не универсален | `reshape(-1,4)` | Регрессионный тест, CI |
| v1.2.2: неизвестно, получен ли /start вторым аккаунтом | Недостаток логов источника whitelist и получения обновлений | Безопасные логи allowed/denied | Нужен живой запуск бота |
| v1.3: после рестарта обрабатываются старые фото | Telegram хранит updates до подтверждения offset | Инициализация offset по последнему старому обновлению | Очередь пропускается **намеренно** |
| v1.3: бледный текст на пожелтевших страницах | Слабый локальный контраст | Умеренный unsharp только на L с нейтральной маской | Нельзя восстановить потерянную информацию под бликом |

## Приёмка
1. В режиме `IMAGE_PROCESSING.enabled=false` сохранена прежняя обрезка и обработка глубины цвета.
2. При `confidence=0` не применяется опасный перспективный warp, но мягкие тени/контраст имеют право работать.
3. Контраст не должен перекрашивать насыщенные обложки; тень у корешка не удаляется полностью.
4. Deskew по горизонтальным линиям требует согласования минимум двух разнесённых по высоте границ; при неоднозначности не выполняется.
5. Регрессионные тесты: два разрешённых пользователя, EXIF, legacy crop, параметры, OpenCV, очереди и нейтральная/цветная обработка.
6. Производительность: локально на увеличенном до 2200×3000 изображении около 2.0–2.4 с (без сети); целевое 3–5 с требует проверки на компьютере эксплуатации.

## Ограничения
- Пока нет проверенного эталонного набора 20–30 кадров с ручной разметкой crop и порогами допустимого изменения цвета.
- Сильные блики, полутоновые страницы, подгибы, неровный свет и сложный фон не гарантируют идеального результата.
- Запуск Windows и Telegram в пользовательском окружении не воспроизводился в CI.
- В обработчике ошибок отправки update может подтверждаться и пропускаться; повторные отправки и дедупликация потребуют отдельной инженерной ревизии.
- `flush_updates_on_start=true` намеренно отменяет обработку сообщений, накопившихся за время остановки; для обратного поведения установить `false`.
